# ChatSphere — Frontend

TanStack Start (React 19) frontend for ChatSphere. See the [root README](../README.md) for the full project overview, architecture, and API reference.

## Development

Requires Node.js and npm.

```sh
git clone <this-repository-url>
cd ChatSphere/frontend
npm install
npm run dev
```

Copy `.env.example` to `.env` and set `VITE_API_URL` to your backend's origin before running.
